# Integration of ModSecurity Logs with Parsing, Database Storage, and MISP
## Overview
This project provides an external integration with **ModSecurity**, designed to:

- Parse logs generated by the ModSecurity Web Application Firewall (WAF).
- Extract relevant security data through automated parsing.
- Store parsed events in a relational database.
- Expose data via a web application for management and visualization.
- Send Indicators of Compromise (IoCs) to MISP (Malware Information Sharing Platform) for threat intelligence sharing and enrichment.

## Objectives
- Automate the analysis and handling of ModSecurity logs.
- Facilitate the correlation and sharing of security events through MISP.
- Provide a user-friendly web interface for reviewing and exporting data.
